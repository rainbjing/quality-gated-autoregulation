NSCA 智能体能训练系统 + FitMotion 动作姿态分析
==================================================

【怎么打开】

  Windows : 双击  Start-Windows.bat
  macOS   : 双击  Start-Mac-Linux.command
            （第一次可能提示“无法验证开发者”：右键点它 → 打开 → 再点“打开”）
  Linux   : 在终端运行  ./Start-Mac-Linux.command

  浏览器会自动打开  http://localhost:8765/NSCA-FitMotion.html
  关闭启动脚本的窗口，服务就停止了。下次想用，再双击一次。

  这个小服务器只监听你这台电脑（127.0.0.1），局域网里的其他设备访问不到。
  Windows 版使用系统自带的 PowerShell，不需要安装 Python。
  macOS / Linux 版需要 Python 3（macOS 通常已带；没有的话脚本会告诉你怎么装）。


【为什么要用启动脚本，不能直接双击 HTML？】

  直接双击 HTML（地址栏以 file:// 开头）也能打开，「视频上传分析」都能用。
  但「摄像头实时训练」不行：Chrome 会拒绝嵌在页面里的 FitMotion 请求摄像头
  （我们在 Chrome 里实测过）。通过 localhost 打开就没有这个限制。

  只用「上传视频分析」、不用摄像头的话，直接双击 HTML 也可以。
  如果是 file:// 打开，「🎥 动作分析」页顶部会有黄色提示。


【重要：数据按“网址”分开保存】

  你的所有数据（档案、打卡、计划、动作分析记录……）都保存在浏览器里，
  并且是按“网址 + 端口”分开存的。下面这些是互不相通的“不同位置”：

      双击打开 (file://...)        ←→   http://localhost:8765/...
      http://localhost:8765/       ←→   http://127.0.0.1:8765/   （别用 127.0.0.1 访问）
      Chrome                       ←→   Safari / Edge / Firefox

  所以：
   * 请始终用同一种方式打开（建议只用启动脚本）。
   * 启动脚本的端口固定是 8765，不要改。
   * 如果你之前是双击 HTML 用的，换成启动脚本后会发现“数据没了”——没丢，
     只是在另一个位置。迁移方法：
       ① 用原来的方式打开 → 页面顶部点「💾 备份 / 恢复」→「导出全部数据」，保存 .json 文件
       ② 用启动脚本打开 → 「💾 备份 / 恢复」→ 选择那个 .json → 覆盖导入
   * 清理浏览器缓存、换浏览器、换电脑都会让数据“消失”。请定期导出备份。
     页头的「💾 备份 / 恢复」按钮上出现黄点，表示该备份了。
   * 备份文件里不包含 FitMotion 的 API Key（防止备份文件外传时泄露），
     换环境后需要在 FitMotion 里重新填写。


【手机上使用】

  界面已经适配手机（FitMotion 在窄屏下为单列布局）。但要注意：

   * 这个程序需要通过“网址”打开，手机上没法运行启动脚本。你需要把
     NSCA-FitMotion.html 放到一个 https 的静态网站上（例如 GitHub Pages、
     Netlify 等），然后在手机浏览器里打开那个网址。
   * 摄像头只在 https 或 localhost 下可用；用电脑的局域网地址
     （http://192.168.x.x:...）在手机上打开，摄像头会被拒绝。
   * 数据只存在你那台手机的浏览器里，和电脑上的数据不互通。需要同步时，
     用「备份 / 恢复」导出再导入。
   * 放到公开网站上，别人也能打开这个网页，但看不到你的数据（数据在你自己的
     浏览器里，不在网站上）。


【常见问题】

  Q: 提示“端口 8765 已被占用”？
  A: 有别的程序占用了这个端口。关掉它再试；不要改端口（会导致数据看不见）。
     如果是上一次的服务没关干净：macOS/Linux 在终端运行  pkill -f "http.server 8765"，
     Windows 在任务管理器里结束 PowerShell 相关进程。

  Q: 姿态模型一直“加载中…/降级模式”？
  A: 模型文件要联网下载（来自 CDN）。检查网络；公司/校园网可能屏蔽。

  Q: 视频会上传到服务器吗？
  A: 不会。视频分析全部在你的浏览器里完成，视频和画面都不会发出去。
     唯一会联网发送数据的是“AI 报告”：只有当你在 FitMotion 里填了自己的
     Anthropic API Key，扫描完成后才会自动把【文字摘要】（关节角度数值、
     问题标签、评分等）发给 Anthropic 生成报告。不填 Key，就不会发送任何东西。
     API Key 只保存在你本机的浏览器里。

  Q: Windows 提示“已保护你的电脑”(SmartScreen)？
  A: 点“更多信息”→“仍要运行”。脚本是纯文本，可以用记事本打开查看内容。


【文件说明】

  NSCA-FitMotion.html        主程序（单个文件，内含 FitMotion）
  Start-Windows.bat/.ps1     Windows 启动脚本
  Start-Mac-Linux.command    macOS / Linux 启动脚本
  src/                       开发用：两个源文件 + 构建脚本，日常使用不用管
      nsca.html  fitmotion.html  build.py
      重新生成单文件：  python3 build.py --out ../NSCA-FitMotion.html
      （src 里的两个文件放在同一文件夹，直接打开 nsca.html 也能用，FitMotion 作为独立文件加载。）
